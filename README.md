# KT_39_Ring_Butter

# Вариант 1. Кольцевой буфер
1) class CircularBuffer<T> : IEnumerable<T> с фиксированной ёмкостью, заданной в конструкторе, хранящий данные во внутреннем массиве T[].
2) Метод Add(T item): если буфер не заполнен — добавляет в следующий свободный слот; если заполнен — переписывает самый старый элемент (тот, что был добавлен раньше всех среди ещё хранящихся).
3) GetEnumerator() через yield return, обходящий элементы в правильном логическом порядке — от самого старого из хранящихся к самому новому, с учётом кольцевого сдвига индексов (а не в порядке физических ячеек массива).
4) Дополнительный метод IEnumerable<T> Reverse(), обходящий элементы в обратном порядке — от самого нового к самому старому.
5) Продемонстрируйте: заполнение буфера до предела, добавление сверх предела (с переписыванием старых элементов), обход через foreach и через Reverse().

# Ограничения
Логика обхода обязана быть реализована именно через yield return внутри метода-итератора — не через предварительное построение List<T> со всеми элементами и возврат этого списка. Для Варианта 2 рекурсия обязательна: GetEnumerator() и Leaves() должны вызывать сами себя на вложенных подкатегориях, а не ограничиваться одним уровнем вложенности.
